Live aircraft positions on a 3D globe (CesiumJS). Click anywhere on the globe to set a search centre — the demo shows the aircraft 3D-closest to that point and re-ranks them as you move. True 3D: altitude is part of the distance.

Maintenance

Refresh re-fetches positions from airplanes.live and rebuilds the index. Reset clears OPFS state including the cached UniDic dictionary.

Auto-refresh pauses while the tab is hidden so airplanes.live is not hammered while you are not looking. The manual Refresh button is rate-limited to one request every 5 seconds.

Left drag to rotate · right drag to tilt · scroll wheel to zoom · click the globe to move the search centre 📌.

Search

When off the demo returns every aircraft matching the text query. When on it ranks aircraft by 3D Euclidean distance from the pin (altitude included), keeps the top 50, and AND-combines that with the text condition.
